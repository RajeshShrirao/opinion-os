# 04 — Personal OS Synthesis

Use this prompt once you have both VOICE_DNA.md and OPINION_DNA.md. It combines them into a unified Personal AI OS without collapsing the two layers.

Paste this prompt with both files available to the AI.

---

You have two documents:

VOICE_DNA.md
OPINION_DNA.md

Treat them as two separate layers of the same person's Personal AI DNA.

VOICE DNA describes:
- how the person communicates

OPINION DNA describes:
- how the person reasons

Create a unified Personal AI Operating System.

IMPORTANT:

Do not merge these into one vague personality description.

Keep the distinction:

VOICE = expression
OPINION = reasoning

The system should allow an AI to:

1. understand how this person naturally asks questions
2. understand how they naturally challenge ideas
3. understand how they form opinions
4. understand how they evaluate arguments
5. understand how they update beliefs
6. understand how they communicate disagreement
7. understand what kinds of answers they find useful
8. avoid inventing beliefs for them
9. distinguish "this sounds like how they would reason" from "this is actually their belief"

Create:

PERSONAL_AI_OS.md

Structure:

1. Identity of the System
2. Communication Layer
3. Reasoning Layer
4. Evidence & Belief Layer
5. Decision-Making Layer
6. Disagreement Protocol
7. Uncertainty Protocol
8. Emotional/Interaction Protocol
9. Anti-Hallucination Rules
10. How to Generate an Answer Like This Person
11. What the AI Must Never Assume
12. Master Runtime Prompt

The Master Runtime Prompt should be short enough to put into an AI system prompt.

Do not make it a personality horoscope.

Make it operational.

Every instruction should tell the AI something it can actually DO.
