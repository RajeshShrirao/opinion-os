# 07 — OPINION DNA Update

Use this prompt when you have an OPINION_DNA.md and new conversation history or new beliefs, and you want to update the opinion profile without rewriting it from scratch.

Paste this prompt with the existing OPINION_DNA.md and the new material available to the AI.

---

You are updating an existing Personal AI DNA system.

Files available:

OPINION_DNA.md

New conversation history is also available.

Analyze ONLY the new material for changes.

Do not rewrite the entire profile from scratch.

Identify:

1. New recurring communication patterns
2. Patterns that became weaker
3. Patterns that disappeared
4. New vocabulary or phrasing
5. Changes in how the person expresses disagreement
6. Changes in how they form or update opinions
7. Changes in evidence preferences
8. Changes in uncertainty tolerance
9. Changes in decision-making
10. Contradictions with the existing DNA

For every proposed change, classify it:

- CONFIRMED CHANGE
- POSSIBLE CHANGE
- ONE-OFF / IGNORE

Do not update the DNA based on one unusual message.

Only modify a stable rule when enough evidence supports the change.

Preserve historical information when useful.

Do not erase an old pattern merely because the person temporarily behaved differently.

Then produce:

OPINION_DNA_UPDATE.md

and a concise list of recommended changes to the master Personal AI OS.
