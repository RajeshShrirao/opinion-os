# Code of Conduct

## Our Pledge

We want to keep this project a welcoming, constructive place for everyone who wants to contribute or use it.

## Expectations

- Be respectful and constructive in discussions and issues.
- Focus on the work, not the person.
- When you disagree, engage with the actual point, not the person.
- Do not use contributions to harass, attack, or exclude others.

## Scope

This Code of Conduct applies in all project spaces: issues, pull requests, discussions, and any other project-related communication.

## Enforcement

If you experience or witness behavior that violates this Code of Conduct, open an issue and describe what happened. The maintainer will review it and take appropriate action, including editing or removing content, or blocking contributors.
